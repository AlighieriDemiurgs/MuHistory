**0.34 aka 0.34.0 (03.08.2001):**

- Introduction of 3<sup>rd</sup> character: Fairy Elf (FE) in addition to Dark Knight (DK) and Dark Wizard (DW).<sup><a id="cite5"></a>[[5]](#ref5)</sup>

- Introduction of Fairy Elf (FE) items: Vine set, Silk set, Wind set, Spirit set, Short Bow, Crossbow, Bow, Golden Crossbow, Elven Bow, Arquebus, Battle Bow, Light Crossbow, Tiger Bow, Serpent Crossbow.<sup><a id="cite5"></a>[[5]](#ref5)</sup>

- Added map Noria.<sup><a id="cite5"></a>[[5]](#ref5)</sup>

- Added Healing Orb, Orb of Greater Damage and Orb of Greater Defense.<sup><a id="cite5"></a>[[5]](#ref5)</sup>

**0.35 aka 0.35.0 (10.08.2001):**

- Added semi-automatic reload for bows and crossbows by pressing the 'E' key. Previously you had to insert the arrows/bolts in the inventory 'I' view each time.<sup><a id="cite6"></a>[[6]](#ref6)</sup>

- Added different colored glow to +7 items. Maximum item level is +7 at this point.<sup><a id="cite6"></a>[[6]](#ref6)</sup>

A likely explanation is that Unicorn (Storm Crow) Armor has Item level 80, Unicorn (Storm Crow) Pants have Item level 74. The strongest monster in Atlans is Hydra with Monster level 74.<sup><a id="cite13"></a>[[13]](#ref13)</sup>
  - However, on test server and test patch Hydra was level 72.<sup><a id="cite106"></a>[[106]](#ref106)</sup> Therefore, it could not drop Unicorn (Storm Crow) pants with an Item level 74. Likely Hydra's drop table was not adjusted initially even though it was released as a level 74 monster on the main server.

- Maximum level limit increased from 255 to 298.<sup><a id="cite13"></a>[[13]](#ref13)</sup>
  - Discrepancy exists since live evidence does not support the claim. The publicly available 0.75 KOR protocol client, while running on OpenMU server, still has the maximum level of 255.
